# MindEase — Student Well-being Website

MindEase is a team-based frontend website prototype focused on student well-being, self-care, stress management, and relaxation.

## Project Overview

The project aims to provide students with a user-friendly digital space to explore well-being resources and self-care activities.

## Features

* Learning resources
* Self-care information
* Relaxation activities
* Student support resources
* Mood-based page concepts

*Note: Features may vary based on the current implementation.*
